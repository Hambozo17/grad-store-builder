# 0001 Workspace Structure

## Decision

Use `docs/` as the single home for planning, architecture, specs, research, references, notes, logs, decisions, and archived material.

## Reason

The project is entering a planning-heavy phase with many drafts and research inputs. A clear folder structure prevents loose files, duplicate context, and unclear source material.

## Consequences

- Root stays focused on active agent/tool configuration.
- Research material is preserved but separated from plans.
- Future implementation plans should start from `docs/plans/_plan-template.md`.
