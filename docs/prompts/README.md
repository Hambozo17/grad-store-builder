# Prompt Workbench

This folder contains reusable prompts for preparing, verifying, and implementing Version One.

## How To Use

1. Use `00-master-planning-prompt.md` when an agent needs to understand the full workspace.
2. Use `01-proposal-scope-refinement-prompt.md` to keep the graduation proposal aligned with authenticated Version One.
3. Use `02-brand-prompt-intake-deep-prompt.md` for Brand Prompt Intake planning.
4. Use `03-store-generation-deep-prompt.md` for Store Generation planning.
5. Use `04-research-synthesis-prompt.md` to convert research into Version One risks and requirements.
6. Use `05-open-door-architecture-review-prompt.md` to check extension boundaries.
7. Use `06-plan-phase-kickoff-prompt.md` before a focused implementation plan.
8. Use `07-search-and-confirmation-deep-prompt.md` before implementation to verify current docs.
9. Use `08-expanded-ecommerce-platform-implementation-plan-prompt.md` for the full authenticated Version One plan.

## Prompt Rules

- Prompts must reference workspace files directly.
- Prompts must require file verification before claims.
- Prompts must use the current Version One scope: auth, tenants, credits, Super Admin, AI gateway, intake, generation, storefront, cart, mock checkout, verification, and polished UI.
- Prompts must keep Stripe/live payments, live Shopify, campaigns, arbitrary drag-and-drop, marketplace/add-ons, and vendor payouts out of Version One.
- Search prompts must distinguish verified facts, source-backed claims, and project assumptions.
